## 3. Run the application

```bash
python3 -m src.cli --help

# add some work
python3 -m src.cli add "Write the report" --priority high --tag docs
python3 -m src.cli add "Answer support ticket" --priority urgent
python3 -m src.cli add "Update changelog" --priority low

# list it, ordered by severity (fixed by the pipeline: urgent → high → medium → low)
python3 -m src.cli list --sort priority

# statistics — works on an empty / never-completed store (fixed by the pipeline)
python3 -m src.cli stats

# complete a task, then look again
python3 -m src.cli complete 1
python3 -m src.cli stats

# export a report (path traversal is now rejected)
python3 -m src.cli export report.txt
python3 -m src.cli export "../../etc/evil.txt"    # refused, exit code 2

# destructive admin action, requires the configured token
TASKTRACKER_ADMIN_TOKEN="choose-a-long-random-value" \
  python3 -m src.cli admin clear --token "choose-a-long-random-value"
```

Tasks are stored in `data/tasks.json` by default; pass `--store /tmp/my.json` to use a scratch file.

| Exit code | Meaning |
|---|---|
| `0` | success |
| `2` | validation error (bad input, unknown task id, rejected export path) |
| `3` | forbidden (admin token missing or wrong) |

## 5. Re-run the agent pipeline

The pipeline is one command. It runs all six agents in order and loads each agent's declared skills
automatically.

```bash
./run-pipeline.sh --dry-run      # show stages, models, skills and cache decisions; costs nothing
./run-pipeline.sh                # run; stages whose output already exists are skipped
./run-pipeline.sh --force        # re-run every stage from scratch
```

Because every artifact from the graded run is committed, a plain `./run-pipeline.sh` reports
`CACHED` for all six stages and still runs the test suite — that is the free way to verify the
plumbing. Use `--force` to actually spend tokens and regenerate.

### Options

| Flag | Effect |
|---|---|
| `--dry-run` | Print the plan only; no agent is invoked |
| `--force` | Ignore cached artifacts and re-run every selected stage |
| `--from <stage>` | Start at a stage, skipping the earlier ones |
| `--only <stage>` | Run exactly one stage |
| `--bug <ID>` | Operate on a different bug folder under `context/bugs/` |
| `-h`, `--help` | Usage |

Stage names: `bug-researcher`, `research-verifier`, `bug-planner`, `bug-fixer`,
`security-verifier`, `unit-test-generator`.

### What a full re-run costs

A `--force` run makes six headless `claude -p` calls (three on `claude-opus-5`, three on
`claude-sonnet-5`). The exact per-stage cost and duration of the recorded run are in
`artifacts/pipeline-run.md`. Lower the ceiling per stage with `PIPELINE_MAX_USD=2 ./run-pipeline.sh --force`.

> **Re-running `--force` rewrites the fixed source files.** The agents work on the code as it is now,
> which is already fixed — so a forced re-run produces a *no-op* fix summary rather than reproducing
> the original repair. To watch the original repair happen again, restore the seeded defects first
> (`git stash` your local state, or check out the pre-fix commit of `src/`), then run `--force`.

### Where output goes

| Path | Contents |
|---|---|
| `context/bugs/BUG-001/` | the seven pipeline artifacts (bug context → test report) |
| `artifacts/pipeline-run.md` | run summary: stage, model, status, duration, cost, turns |
| `artifacts/logs/<run-id>/` | per-stage transcript (`*.log`) and raw result metadata (`*.result.json`) |
| `docs/screenshots/` | screenshots of the real run, plus the raw transcripts they were rendered from |

## 7. Troubleshooting

| Symptom | Cause and fix |
|---|---|
| `the 'claude' CLI is not on PATH` | The pipeline needs Claude Code. Install it, or just inspect the committed artifacts — the app and tests work without it. |
| `pytest is missing` | `pip install -r requirements.txt` |
| `ModuleNotFoundError: No module named 'src'` | Run from `homework-4/` and use `python3 -m src.cli`, not `python3 src/cli.py` |
| Pipeline says `CACHED` for every stage | Intended. Add `--force` to regenerate. |
| `stage '<name>' did not produce its declared output` | The agent ended without writing its artifact. Read `artifacts/logs/<run-id>/<NN>-<name>.log`, then re-run that stage with `--only <name> --force`. |
| `admin clear` always returns exit code 3 | Correct after the fix: set `TASKTRACKER_ADMIN_TOKEN` and pass the same value to `--token`. |
| Export refuses a filename | Correct after the fix: the resolved path must stay inside `--export-dir`. |
